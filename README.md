# Global Floating Raft Aquaculture

This repository accompanies our study on individual-level mapping
of floating raft aquaculture using Sentinel-1 and Sentinel-2 imagery.

The study examines the mapped raft footprint, environmental and
accessibility factors associated with raft distribution, predicted
suitable coastal space, and environmental contrasts between
raft-occupied and non-raft waters.

## Data and Code Availability

This repository currently contains a project overview only.
The derived raft maps, analysis datasets and source code are
being prepared and will be released upon publication.
